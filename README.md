# DevOps Project – Git 

## Objective
Manage a DevOps project using Git and GitHub best practices.

## Tools
- Git
- GitHub

## Branching Strategy
- main → production-ready code
- dev → development branch
- feature/* → new features

## Workflow
1. Create feature branch
2. Commit changes
3. Raise Pull Request
4. Merge into dev
5. Merge dev into main
